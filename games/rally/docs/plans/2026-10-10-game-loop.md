# Game Loop (Phase 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A game around the generated tracks: title menu, Free drive / Stage / Time attack, a
countdown with the car held, timing with checkpoints, splits, laps and saved bests, pause and
results menus, working on phones and iPads.

**Architecture:** A headless `src/game/` layer (progress, pace, modes, `Game` state machine,
bests) driven once per physics step from `main.js`; DOM menus and HUD in `src/menus.js`; one
`hold` flag added to `Vehicle`; an orbit camera in `render.js` for the title.

**Tech Stack:** plain ES modules, three.js 0.160, rapier3d-compat 0.14, esbuild, Node test
scripts, playwright-core for `test/mobile.mjs`.

**Spec:** `docs/spec/tracks-spec.md` → "Requirements — Phase 2" (T-20 … T-27). Car/physics:
`docs/spec/rally-spec.md`.

## Global Constraints

- `src/game/` imports nothing from three.js, Rapier or the DOM (Rapier objects come in via `sim`).
- Game time is sim time: `game.step()` is called once per `sim.step()` (DT = 1/240 s).
- Match the code style: terse ES modules, short "why" comments, no new dependencies.
- Tests are Node scripts printing `PASS/FAIL name: value [lo..hi]`, exit non-zero on failure,
  `node test/<file>.mjs [filter]`.
- Do not git commit (the user commits / releases).
- Existing suites keep passing (`npm test`, `npm run test:mobile` updated for the title screen).
- Touch: safe areas through `--sa-*`; buttons ≥ 44 px (pedals ≥ 56 px); nothing that takes a
  drag within 20 px of the left edge.

### Task 2: Pace + run-up

**Interfaces:**
```js
allowedSpeed(track, s, { lat = 0.55, caps = CAPS } = {}) -> m/s   // min(V_MAX, sqrt(lat·μ·g/|κ|), obstacle cap)
runUpDistance(track, lineS, { time = 10, accel = 0.45, brake = 0.4, lo = 150, hi = 400 } = {}) -> m
export const V_MAX = 38, CAPS = { kicker: 12, whoops: 12, crest: 16, tabletop: 16 }
```
`runUpDistance`: 3 fixed-point iterations of D (start 250): speed envelope per metre over
`[lineS − D, lineS]` (backward braking pass at `brake·μ·g`), forward pass from rest at
`accel·μ·g` capped by the envelope, distance where time reaches `time`; clamp `[lo, hi]`.

- [x] Tests: `runUpDistance` within 150–400 on 4 loop seeds; flat straight sanity — allowedSpeed
  on a straight is V_MAX; autopilot drive in `test/track.mjs` unchanged (run it).
- [x] Move `CAPS`, `V_MAX`, `OBSTACLE_*`, `obstacleCap` from `test/autopilot.js`; autopilot calls
  `allowedSpeed(track, pk.s, { lat, caps })` per sample.

### Task 3: Progress

**Interfaces:**
```js
makeProgress(track, { maxD = 15, jump = 50, missAfter = 30 } = {}) -> {
  reset(p0),          // course position p (m from the start line; negative = before it)
  update(x, z) -> Event[]  // { type: 'start' } first forward crossing of p = 0
                           // { type: 'checkpoint', index, lap }
                           // { type: 'missed', index }
                           // { type: 'line', lap, valid }      (loop: each lap end)
                           // { type: 'finish' } | { type: 'blocked', index }  (stage)
  p, lap, next, missed, cps: number[] /* checkpoint p's within a lap */, lapLength
}
```
Loop: `lineS = gates[0].s`, `lapLength = length`, `cps = (cp.s − lineS) mod length`, sorted.
Stage: `lineS = start gate s`, finish at `finishGate.s − lineS`.

- [x] Tests (synthetic `track`-shaped objects built from a straight/circle layout + `makeLocator`):
  checkpoints in order; loop wrap gives `line` with lap 1 valid; jump of 100 m credits nothing
  and raises `missed`; driving back credits and clears; stage finish blocked then OK; backwards
  crossing ignored; |d| > 15 m crossing ignored.
- [x] Implement.

### Task 4: Bests + modes + Game

**Interfaces:**
```js
bestKey(modeId, track, carId) -> 'stage|seed|kind|style|theme|density|car'
makeBests(storage = globalThis.localStorage) -> { get(key) -> obj|null, put(key, obj) }  // try/catch
MODES = { freeDrive, stage, timeAttack }  // { id, label, kind, countdown, clock: null|"go"|"line", laps, startOffset(track) }
class Game {
  constructor(sim, { bests })
  state                 // 'title'|'loading'|'ready'|'countdown'|'running'|'finished'|'paused'
  mode, track, time, lapTime, laps: [{ time, valid, best }], splits, best, countN
  on(fn)                // events { type, ... }
  setMode(mode, carId)  // stores; track comes from sim.world.track
  title()               // place car at start pose, hold, state 'title'
  loading()
  begin()               // place car, reset progress; freeDrive → 'running', else 'ready'
  restart()             // props home + begin()
  pause() / resume()
  step()                // once per sim.step(): timers, hold, progress, finish brake
  startPose() -> {x,y,z,yaw}
}
```
- [x] Tests: bests only replaced when better; Stage via autopilot from Go to `finished`
  (seed 'g1', twisty summer stage): `time` ≈ sim time since Go ± DT, one split per checkpoint,
  finish event with `isBest` true first run, false-with-delta on a slower second record;
  teleport past a checkpoint (`car.reset` 120 m ahead) → `blocked` at the finish until driven
  back (here: teleport back before it, continue → finish). Time attack seeds 'ta1','ta2': clock
  0 until the line, then ≥ 2 valid laps within 400 s sim, lap times > 30 s; countdown takes
  3.8 s ± DT from `begin()` to `running`.
- [x] Implement `bests.js`, `modes.js`, `game.js`.
